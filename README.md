## Start

Przed rozpoczęciem upewnij się, że:

* Antywirus jest wyłączony
* Masz Windows 10/11
* Najlepiej uruchomić `.exe` jako Administrator
* Zalecane jest uruchomienie programu na maszynie wirtualnej (VM)

> Uruchamiasz program na własne ryzyko.

## O wirusie

Program jest czymś w stylu Windows Party Mode.

1. Program nie posiada stealera.
2. Posiada mechanizm Anti Alt+F4.
3. Może powodować nietypowe zachowanie systemu Windows.
4. Zalecane jest uruchamianie go na maszynie wirtualnej, jeżeli nie ufasz programowi.
5. Nie ponoszę odpowiedzialności za szkody wyrządzone przez program.

## Rozwiązywanie problemów

### Problem: Brak wymaganego API lub sterownika

**Rozwiązanie:**
Poszukaj oficjalnego instalatora sterownika lub API, którego program potrzebuje do działania.

### Problem: Antywirus wykrył potencjalnie niechcianą aplikację

**Rozwiązanie:**
Program może być wykrywany przez system antywirusowy ze względu na sposób jego działania.

Jeżeli pobrałeś program z tego repozytorium i ufasz jego źródłu, sprawdź dokładnie komunikat antywirusa przed podjęciem dalszych działań.
